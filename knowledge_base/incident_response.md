# Cybersecurity Incident Response

## Purpose

Incident response is the structured process used to detect, analyze, contain, eradicate, and recover from cybersecurity incidents.

## Core Stages

### Identification

Determine whether the observed activity represents a security incident.

Collect:
- Security alerts
- Authentication logs
- Network logs
- Endpoint events
- Relevant timestamps
- IP addresses
- User accounts

### Analysis

Determine:
- What happened
- When it happened
- Which systems or accounts were affected
- Associated indicators
- Whether the activity is ongoing
- Potential security impact

### Containment

Limit the impact while preserving evidence.

Possible defensive actions:
- Block confirmed malicious indicators
- Isolate affected endpoints
- Disable compromised accounts
- Apply rate limits
- Restrict suspicious access

### Eradication

Remove the underlying cause.

Examples:
- Remove malicious software
- Reset compromised credentials
- Remove unauthorized access
- Fix security weaknesses

### Recovery

Restore normal operations and monitor for recurring suspicious activity.

### Lessons Learned

Document:
- Root cause
- Timeline
- Impact
- Actions taken
- Detection gaps
- Required improvements
